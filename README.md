
# TurboÉrettségi – Test Automation

Automated UI testing project for the [TurboÉrettségi](https://turboerettsegi.hu/) web application.

## Technologies
- Python
- Selenium WebDriver
- pytest
- Page Object Model (POM)
- Allure Reports

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running Tests

```bash
pytest
```

🚧 Work in progress.

Independent QA automation project focused on automated testing, maintainability, and practical experience with Selenium and Python.
